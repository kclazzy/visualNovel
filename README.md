# Visual Novel Studio

Редактор визуальных новелл и игровой движок на Rust. Автор без навыков программирования
собирает историю из сцен, реплик, выборов и веток, проверяет её прямо в редакторе
и выпускает самостоятельную игру — для Windows и для телефона.

## Что умеет

- **Сцены и события.** Фон, персонажи, реплики, мысли, музыка, звуки, паузы, затемнения, переходы,
  выборы, переменные, условия, концовки. Порядок событий задаёт автор в таймлайне.
- **Сцена перед глазами.** В центре видно экран после выбранного события; персонажей двигают мышью,
  фон и персонажей перетаскивают из левой панели.
- **Сюжет узлами.** Сцены и переходы на одной схеме: узлы двигаются, соединяются мышью, создаются и удаляются.
- **Главы, шаблоны, копирование** сцен и глав.
- **Гардероб героя.** Одежда — слои поверх спрайта; игрок выбирает образ, предметы открываются по сюжету.
- **Предпросмотр** тем же кодом, что и готовая игра, с отладкой (сцена, событие, переменные, выборы).
- **Проверка проекта.** Битые переходы, недостижимые сцены, пустые реплики, отсутствующие файлы,
  необъявленные переменные; щелчок по замечанию ведёт к месту. Ошибки блокируют сборку.
- **Концовки.** Сколько их, через какие сцены к ним идут и какие выборы на них влияют.
- **Сборка игры для Windows** — папка с `.exe`, редактор и Rust игроку не нужны.
- **Версия для телефона** — веб-игра (PWA): открывается в браузере телефона, ставится на главный экран.
- **Обновление истории одним файлом `.vnpak`** без потери сохранений игроков.
- **ИИ по желанию** — облачный или локальный — пишет черновик истории или продолжает сцену.
- **Кнопка «Обновить редактор»** ставит новую версию из выпусков этого репозитория.

## Установка

Готовая сборка: раздел [Releases](https://github.com/kclazzy/visualNovel/releases) → архив
`vn-studio-…-windows.zip` → распаковать в любую папку → запустить `vn-studio.exe`.
Файл `vn-player.exe` должен лежать рядом: из него редактор делает игры.

Сборка из исходников (нужен [Rust](https://rustup.rs)):

```
cargo build --release -p vn-studio -p vn-player
target/release/vn-studio
```

На Linux перед сборкой: `sudo apt install libasound2-dev`.

## Первые шаги

1. **Новый** → название → способ: вручную, с помощью ИИ или демо-проект «Свет маяка».
2. Вкладка **Ресурсы**: импортируйте фоны, спрайты, музыку (или перетащите файлы в окно).
3. Вкладка **Персонажи**: создайте персонажей и назначьте им изображения.
4. В таймлайне справа: **+ Событие** или **Шаблон**. Свойства события — под сценой.
5. Вкладка **Сюжет**: соедините сцены. **Проверить** → **▶ Предпросмотр** (F5).
6. **Собрать** → игра для Windows, версия для телефона или обновление истории.

Горячие клавиши: Ctrl+S — сохранить, Ctrl+Z / Ctrl+Y — отменить / повторить, F5 — предпросмотр,
Del — удалить событие, Ctrl+D — дублировать событие.

## Игра на телефоне

**Собрать → Версия для телефона** создаёт папку `builds/<имя>-web/` и архив `builds/<имя>-web.zip`.

- **Проверить сразу:** в окне «Готово» нажмите «Проверить на телефоне (Wi-Fi)» и откройте
  показанный адрес в браузере телефона, подключённого к той же сети.
- **Опубликовать:** загрузите архив на [itch.io](https://itch.io) (тип проекта HTML) или содержимое
  папки на любой хостинг с https (GitHub Pages, Netlify). С https игру можно «Добавить на главный экран»,
  после первого запуска она работает без интернета.

Сохранения на телефоне хранятся в браузере. Отдельный APK редактор не делает (см. ограничения).

## Подключение ИИ

Вкладка **ИИ** содержит мини-инструкцию. Коротко:

- **Локально:** установите [Ollama](https://ollama.com) или [LM Studio](https://lmstudio.ai), скачайте модель,
  выберите в редакторе «Ollama (локально)» / «LM Studio (локально)» → «Список моделей». Ключ не нужен.
- **Облако:** OpenAI, OpenRouter, Anthropic или любой OpenAI-совместимый сервис — вставьте ключ API.

Ключ хранится в настройках редактора на вашем компьютере и не попадает в проект и в игру.
Черновик от ИИ сначала показывается и добавляется в проект только по кнопке.

## Обновление игры без потери сохранений

1. Измените историю, затем **Собрать → Выпустить обновление истории (.vnpak)**.
2. Игрок кладёт файл в папку игры рядом с `.exe` и запускает игру.
3. Игра делает копию сохранений, обновляет историю и продолжает с прежнего места.

Сохранения ссылаются на постоянные ID сцен и событий и лежат отдельно от игры
(Windows: `%APPDATA%\VNStudio\saves\<id истории>`). При удалении сцены редактор спрашивает,
с какой сцены продолжат игроки, сохранившиеся в ней.

## Ограничения версии 0.1

- Телефон — веб-версия (PWA), не APK и не приложение из магазина.
- Сборка Windows и кнопка обновления проверены только автоматической сборкой на GitHub; автор
  разрабатывал и запускал редактор на Linux.
- Одежда слоями — только у главного героя; у остальных персонажей образы задаются выражениями.
- Переименование переменной не переименовывает её использования (проверка покажет их).
- Нет анимаций спрайтов, видео, локализации, плагинов — архитектура их допускает, см. `docs/ARCHITECTURE.md`.
