# Словарь терминов

| Термин | Значение | В коде |
|---|---|---|
| История | Все данные игры: сцены, персонажи, переменные, гардероб | `Story` |
| Проект | Папка с историей и ресурсами на диске автора | `vn_store::project` |
| Глава | Группа сцен для удобства автора; на ход игры не влияет | `Chapter` |
| Сцена | Единица повествования: упорядоченный список событий | `Scene` |
| Событие | Одно действие сцены: фон, реплика, выбор, переход… | `Event`, `EventKind` |
| Выбор, вариант | Событие с вариантами ответа игрока | `EventKind::Choice`, `ChoiceOption` |
| Условие | Выражение над переменными: `доверие >= 5 и не ключ` | `Cond` |
| Переход | Связь сцена → сцена (событие «Переход», вариант выбора, «Условие») | `Edge` |
| Концовка | Событие, завершающее игру | `EventKind::End` |
| Перенаправление | Замена удалённой сцены для старых сохранений | `Story::redirects` |
| Запасная сцена | Куда попасть, если сцены сохранения нет и замены нет | `Meta::fallback_scene` |
| Выпуск | Номер версии сценария, растёт с каждым обновлением | `Meta::story_version` |
| Гардероб, слот, предмет | Одежда героя слоями; слот — место слоя, предмет — изображение | `Wardrobe`, `Slot`, `Item` |
| Рантайм | Состояние идущей игры и правила её продвижения | `Runtime`, `GameState` |
| Вид | Всё, что нужно нарисовать сейчас; одинаков для ПК и телефона | `View`, `Prompt` |
| Сохранение | Состояние игры с ID истории, выпуском и версией формата | `SaveFile` |
| Пакет | Файл `.vnpak` (zip): сценарий, манифест и, если нужно, ресурсы | `vn_store::pack` |
| Черновик | Ответ ИИ в строгом JSON до превращения в сцены | `Draft` |
| Трасса соответствия | Эталон «команды → вид», по которому сверяются Rust- и JS-движки | `player-web/tests/trace.json` |
