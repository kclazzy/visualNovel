## Мутационное тестирование

`cargo mutants -p vn-core`: поймано 351 из 393 жизнеспособных мутантов (89 %; до новых тестов — 327 из 421, 78 %).
Оставшиеся 42: расстановка узлов скопированных сцен и сцен от ИИ (координаты), точные формулировки
подсказки для ИИ, граница длины истории диалогов, высота персонажа по умолчанию, часть анализа концовок.
Остальные модули мутациями не проверялись.

## Чего не сделано из принципов и почему

- Инструментов `crapper` и `dryer` в среде нет; сложность и дублирование проверялись `cargo clippy` и чтением.
- «Красная» фаза TDD (тест падает до кода) соблюдалась не везде: сценарии интерфейса писались после кода окна.
- Проверка доступности (имена полей для экранных дикторов) в тестах интерфейса отключена:
  у части полей ввода нет подписей для вспомогательных технологий.
